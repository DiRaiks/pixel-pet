# Pixel Pet — ТЗ и план работ

Пиксельный кубик на рабочем столе macOS. Показывает, что делают агенты Claude Code и сколько осталось лимита. Умеет быстро ответить на вопрос и перевести выделенный текст. Живёт в чёлке MacBook.

Статус: черновик v1, 2026-10-19.

---

## 1. Цели и не-цели

**Цели**
- Видеть состояние агентов Claude Code без переключения окон: сколько работает, кто ждёт ввода, кто упал.
- Видеть лимиты (5 ч / неделя), модель и заполненность контекста.
- Задать быстрый вопрос и получить ответ, не открывая терминал.
- Перевести выделенный текст хоткеем: локально, без LLM.
- Чтобы было приятно: плавно, живо, ненавязчиво.

**Не-цели (v1)**
- Windows и Linux.
- Approve/deny разрешений агентов прямо из питомца (возможно, в v2).
- Анализ содержимого экрана (Screen Recording, vision).
- Агенты, кроме Claude Code: Codex, Cursor и другие (архитектуру оставляем открытой).
- Публикация в App Store и нотаризация.

## 3. Персонаж

**Кубик**, пиксель-арт. За основу берём прототип: [`prototype/sprites.html`](prototype/sprites.html).

- Холст спрайта 32×32, масштаб только целый (×3 / ×4, настраивается), фильтр `nearest`.
- **Рендер на CALayer** (по итогам M0: SpriteKit тратит 2–8 % CPU, CALayer — 0.1–0.2 %). Кадры — `CGImage` в `layer.contents`, сменяются по таймеру состояния на 6–14 fps. Перемещение, прыжки и пружины — Core Animation (render server, 120 Гц, почти без CPU).
- На старте кадры генерируются **процедурно** в `CGContext` при запуске и кешируются: порт кода прототипа на Swift. В M8 его заменяем спрайт-листом из Aseprite (PNG + JSON с тегами), интерфейс рендерера не меняется.

### 3.1 Состояния и приоритеты

Агрегированное состояние питомца выбирается по приоритету (сверху вниз):

| # | Состояние | Триггер | Анимация (кадры @ fps) |
|---|---|---|---|
| 1 | `error` | У агента ошибка (`StopFailure` / ошибка API) | Тряска, краснеет (12 @ 14), 3 с, потом ниже по списку |
| 2 | `alert` | ≥1 агент ждёт ввода (`Notification`: permission / idle prompt) | Подпрыгивает, «!», смотрит на кубик агента (12 @ 12), в цикле |
| 3 | `celebrate` | Агент завершил задачу (`Stop`) | Большой прыжок, искры (16 @ 12), один раз |
| 4 | `lowLimit` | Лимит 5 ч ≥ 85 % или недельный ≥ 90 % | Пустеет, потеет, дрожит (16 @ 10), фоном |
| 5 | `working` | ≥1 агент работает | Думает, кубики крутятся (12 @ 10) |
| 6 | `idle` | Агентов нет или все простаивают | Дыхание, моргание, взгляд (24 @ 8) |
| 7 | `sleep` | Нет активности пользователя N мин (по умолчанию 10) и нет работающих агентов | Сон, Z-Z-Z (24 @ 6) |

Служебные анимации, вне приоритета: `hop` (реакция на клик), `peek` (чёлка), `dragged` (тянут мышью), `talk` (ответ или перевод).

**Агенты как блоки.** Рядом с телом стоит стопка кубиков 3×3, по одному на сессию, максимум 5 (дальше «+N»). Цвета: работает — бирюзовый со спиннером, ждёт — янтарный и подпрыгивает, ошибка — красный, готово — зелёная вспышка 1 с. Сабагенты показываем мелкой точкой на кубике родителя.

**Лимит как пустота.** Верхние ряды тела светлеют пропорционально израсходованному лимиту 5 ч.

### 3.2 Правила движения (из дизайн-принципов)
- Постоянные анимации (idle) почти незаметны. Яркие — только у редких событий.
- Действия с хоткея (перевод, вопрос) открываются **мгновенно**, без анимации входа.
- Вход медленнее выхода: из чёлки вылезает за ~500 мс с ease-out, прячется за ~250 мс.
- Перетаскивание идёт через spring (инерция и отскок при отпускании).
- `prefers-reduced-motion` (Accessibility → Reduce Motion): без прыжков и тряски, только смена выражения и цвета.

## 4. Функциональные требования

### F1. Окно питомца
- `NSPanel`: borderless, `.nonactivatingPanel`, уровень `.floating`, `collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary, .stationary]`. Не забирает фокус, виден на всех Spaces.
- Клики насквозь везде, кроме непрозрачных пикселей спрайта: hit-test по альфе, `ignoresMouseEvents` переключается динамически.
- Клик — `hop` и открыть или закрыть панель статуса (F6). Правый клик — контекстное меню.
- Позиция и режим (стол / чёлка) запоминаются между запусками.
- Иконка в меню-баре: мини-кубик с цифрой работающих агентов. Меню: показать/спрятать, не беспокоить, настройки, выход.

### F2. Чёлка
- Определение: `NSScreen.safeAreaInsets.top > 0`, геометрия по `auxiliaryTopLeftArea` и `auxiliaryTopRightArea`.
- Режим «дом»: питомец внутри чёлки, видны только светящиеся глаза. Тело рисуется чёрным и сливается с чёлкой.
- `peek`: выглядывает при событии (alert, celebrate, error) и при наведении на чёлку (задержка 300 мс, чтобы не срабатывало при выезде меню-бара в фуллскрине).
- Клик по чёлке, когда питомец дома, раскрывает панель статуса вниз из чёлки.
- Внешний монитор или экран без чёлки: рисуем маленькую чёрную «нору» по центру сверху. **Это основной сценарий** (по M0 ноутбук часто закрыт). Экран для «дома» выбирается в настройках, по умолчанию — экран с меню-баром.
- «Не беспокоить» (хоткей + меню): уходит в чёлку и не выглядывает, кроме `error`.

### F3. Перетаскивание
- Схватить и тянуть: состояние `dragged` (болтается), позиция через spring.
- Отпустить в зоне чёлки (радиус ~60 pt): затягивается внутрь, режим «дом».
- Вытянуть из чёлки вниз: вываливается на стол, `dragged` → падение → squash.
- Бросок с инерцией: короткий «флик» отправляет питомца по экрану с затуханием, но не за пределы экрана.

### F4. Мониторинг агентов (Claude Code hooks)
- Устанавливаемый скрипт `~/.pixelpet/bin/pixelpet-hook`: читает JSON хука из stdin и отправляет одну строку в unix socket `~/.pixelpet/pet.sock`.
  - **Никогда не блокирует Claude**: таймаут 200 мс, всегда `exit 0`, без вывода в stdout.
  - Если задан `PIXELPET_INTERNAL=1` (сессии быстрого вопроса из F7), событие не отправляется.
- События: `SessionStart`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `Notification`, `Stop`, `SubagentStart`, `SubagentStop`, `SessionEnd` (точный список и поля подтверждаем в M0).
- Реестр сессий по `session_id`: состояние, `cwd` (→ имя проекта), модель (из `SessionStart`), последний инструмент, время последнего события, число сабагентов. **Сессия создаётся по любому событию**: у уже открытых сессий `SessionStart` не будет.
- «Ждёт ввода»: `Notification` (permission / idle prompt), а также открытый `PreToolUse` для `AskUserQuestion` / `ExitPlanMode` до парного `PostToolUse`. В auto mode запросов разрешений мало, поэтому эти сигналы обязательны.
- Служебный `SubagentStop` после `Stop` (post-turn summary) не считается сабагентом.
- Сессия без событий 30 мин считается устаревшей и убирается.
- Установщик хуков: мержит в `~/.claude/settings.json`, перед этим делает бэкап, помечает свои записи и умеет полностью удалить их. Чужие хуки не трогает.

### F5. Лимиты, модель, контекст
- **Основной источник лимитов — `rate_limit_event` из `claude -p`** (stream-json, `unifiedWindows.five_hour/seven_day.utilization` и `resetsAt`). Приходит с каждым быстрым вопросом. Если вопросов не было, раз в 30 мин делаем фоновый пинг, но только пока есть активные агенты или открыта панель.
- Для терминальных сессий дополнительно используем **statusline** (для desktop-сессий она не вызывается): ставим команду `pixelpet-statusline`. Она отправляет JSON statusline в сокет и печатает обычную строку статуса (чтобы statusline в терминале остался полезным). Если у пользователя уже есть своя statusline-команда, оборачиваем её: вызываем и передаём её вывод.
- Из statusline берём: модель, % контекста, стоимость сессии и `rate_limits` (5 ч / 7 дн, % и время сброса), если поле есть в текущей версии (проверяем в M0).
- Запасной источник для токенов и стоимости за день: инкрементальный разбор `~/.claude/projects/**/*.jsonl` через `FSEvents`, как у ccusage.
- В UI проценты лимита помечены как оценка.

### F6. Панель статуса
Раскрывается по клику: у питомца на столе — popover рядом, у питомца в чёлке — из чёлки вниз.
- Список сессий: проект, состояние, текущий инструмент, длительность. Клик по сессии открывает её терминал или окно (best effort: через `TERM_PROGRAM` и `cwd`, уточняем в M2).
- Лимиты: две полоски (5 ч, неделя) со временем сброса.
- Модель и контекст активной сессии.
- Быстрые кнопки: «Спросить», «Перевести буфер», «Не беспокоить».

### F7. Быстрый вопрос
- Хоткей (по умолчанию `⌥⌘K`, настраивается) открывает поле ввода в пузыре у питомца, мгновенно.
- Запуск: `claude -p "…" --model haiku --tools "" --setting-sources project --output-format stream-json --verbose --include-partial-messages`, `cwd` = пустая временная папка, env `PIXELPET_INTERNAL=1`. `--bare` не подходит: требует API-ключ.
- Задержки (M0): первый токен ~2.7 с. Ответ готов по `message_stop`, `result` не ждём (он приходит ещё через ~1.4 с).
- Ответ стримится в пузырь (анимация `talk`), есть кнопки «Копировать» и «Продолжить» (follow-up через `--resume <session_id>`).
- `Esc` закрывает пузырь. Запрос можно отменить.
- Если выделен текст, предлагаем добавить его в контекст.

### F8. Перевод (без LLM)
- Хоткей (по умолчанию `⌥⌘T`): взять выделенный текст через Accessibility (`AXSelectedText`). Если не вышло — эмулировать `⌘C` и восстановить буфер обмена.
- Язык определяется `NLLanguageRecognizer`. Направление: ru → en, всё остальное → ru (настраивается).
- Перевод через Apple `Translation` (`TranslationSession`, локально). Если языковой пакет не скачан, показываем подсказку, как его поставить.
- Результат появляется в пузыре у питомца: копировать, заменить выделение (опционально), закрыть по `Esc` или клику вне.
- Нужно разрешение Accessibility. Онбординг объясняет, зачем оно.

### F9. Реакции на рабочий стол
- **Взгляд за курсором**: глаза смещаются на ±1 px в сторону курсора, когда он ближе ~300 pt. Дёшево, но сильно «оживляет».
- Простой пользователя (`CGEventSource.secondsSinceLastEventType`) → `sleep`. Вернулся → `hop` с морганием.
- Сон и пробуждение системы, блокировка экрана → зевок или приветствие.
- Активное приложение (`NSWorkspace.didActivateApplication`): лёгкие реакции, например в терминале или IDE смотрит «по-рабочему». Набор правил задаётся конфигом.
- Фуллскрин-видео или демонстрация экрана → авто-«не беспокоить» (best effort; если не надёжно — только ручной хоткей).

### F10. Настройки
- Хранение: `~/.pixelpet/config.json` + простое окно настроек на SwiftUI.
- Параметры: масштаб, хоткеи, порог сна, языки перевода, модель для вопросов, путь к `claude`, вкл/выкл реакций, автозапуск (`SMAppService`).
- Кнопки: «Установить хуки», «Удалить хуки», «Проверить подключение».

## 6. Архитектура

```
Claude Code ──hooks──► pixelpet-hook ─┐
Claude Code ─statusline► pixelpet-statusline ─┤ unix socket (JSON lines)
                                       ▼
                                 EventServer
                                       ▼
~/.claude/projects/*.jsonl ─FSEvents► UsageReader ─► AppState (@Observable)
NSWorkspace / idle / cursor ─────► DesktopSensor ─►      │
                                                         ▼
                                              PetBrain (state machine + priorities)
                                                         ▼
                              PetRenderer (CALayer) · NotchController · Bubbles (SwiftUI)
Hotkeys ─► QuickAsk (claude -p) / Translator (Translation) ─► Bubbles
```

**Модули (SwiftPM targets)**
- `PetCore` — модели событий, реестр сессий, `PetBrain`, конфиг. Чистый Swift, без AppKit, **покрыт тестами**.
- `PetIntegrations` — `EventServer`, `HookInstaller`, `UsageReader`, `ClaudeLocator`, `QuickAskRunner`, `Translator`.
- `PetUI` — окно, SpriteKit-рендерер, чёлка, пузыри, панель статуса, настройки.
- `PixelPet` — executable, сборка всего вместе.
- `pixelpet-hook`, `pixelpet-statusline` — shell-скрипты на `sh` + `nc -U` (M0: ~10 мс на вызов).

**Протокол** (одна JSON-строка на событие):
```json
{"v":1,"src":"hook","event":"PreToolUse","session_id":"…","cwd":"…","tool":"Bash","ts":1760870000}
{"v":1,"src":"statusline","session_id":"…","model":"…","ctx_pct":42,"rate_limits":{…},"ts":…}
```

**Сборка**: `swift build -c release` → `scripts/bundle.sh` собирает `PixelPet.app` (Info.plist с `LSUIElement=1`, иконка, подпись) → `scripts/install.sh` копирует в `~/Applications`.

## 7. План работ (этапы)

Каждый этап заканчивается демо, которое можно потрогать, и коммитом. Порядок выбран так, чтобы питомец с реальной пользой (счётчик агентов) появился как можно раньше.

### M0. Спайк: проверить допущения (~0.5–1 день)
- [x] Хуки срабатывают для сессий **из Claude desktop (Code tab)**, а не только из CLI. Фиксируем реальные поля событий.
- [ ] Statusline: есть ли `rate_limits`, модель, контекст. Работает ли statusline для desktop-сессий.
- [ ] `claude -p`: путь к бинарнику, флаги стриминга, режим без инструментов, время холодного старта.
- [ ] Прозрачная `NSPanel` + SpriteKit через SwiftPM без Xcode: окно, клики насквозь, 120 Гц.
- [ ] Геометрия чёлки, окно поверх меню-бара.
- [ ] `TranslationSession` из SwiftPM-сборки, наличие языковых пакетов ru/en.
- [ ] Стабильная подпись (self-signed), Accessibility не сбрасывается между сборками.

**Результат:** `docs/spike-notes.md` с фактами и правками этого ТЗ.

### M1. Каркас и живой кубик (~1–2 дня)
- SwiftPM-проект, `bundle.sh`, запуск как agent-app (без Dock).
- Панель, рендерер на CALayer с процедурными кадрами (порт прототипа), все 11 состояний, переключатель состояний в debug-меню.
- Hit-test по альфе, клик → `hop`, перетаскивание с пружиной, запоминание позиции.
- Иконка в меню-баре.

**Приёмка:** кубик живёт на столе, анимации совпадают с прототипом, CPU в покое < 1 %.

### M2. Агенты (~1–2 дня)
- `EventServer`, `pixelpet-hook`, `HookInstaller` (установка, удаление, бэкап) — сначала тесты.
- Реестр сессий, `PetBrain` с приоритетами — сначала тесты.
- Кубики агентов рядом с телом, цифра в меню-баре.

**Приёмка:** запускаю 3 сессии Claude Code — вижу 3 кубика. Одна просит разрешение — питомец в `alert`. Сессия закончила — `celebrate`.

### M3. Лимиты и панель статуса (~1–2 дня)
- `pixelpet-statusline` (с обёрткой существующей statusline), `UsageReader` (jsonl).
- Панель статуса: сессии, лимиты, модель, контекст. Состояние `lowLimit`, «пустота» в теле.

**Приёмка:** цифры в панели совпадают со statusline в терминале с точностью ±2 %.

### M4. Чёлка (~1–2 дня)
- `NotchController`: дом, `peek`, раскрытие панели из чёлки, затягивание при броске, «нора» на внешнем мониторе, «не беспокоить».

**Приёмка:** бросаю кубик к чёлке — он затягивается. Агент просит ввод — выглядывает. Меню-бар не ломается.

### M5. Перевод (~1 день)
- Хоткей, получение выделения (AX → ⌘C fallback), определение языка, `Translation`, пузырь.

**Приёмка:** выделяю абзац в браузере, нажимаю `⌥⌘T`, перевод появляется меньше чем за 1 с, офлайн.

### M6. Быстрый вопрос (~1 день)
- `ClaudeLocator`, `QuickAskRunner` (стриминг, отмена, follow-up), пузырь ввода и ответа, анимация `talk`.

**Приёмка:** `⌥⌘K`, вопрос, ответ стримится. Эта сессия **не** появляется среди кубиков агентов.

### M7. Реакции на стол (~1 день)
